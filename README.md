# 🛡️ Phishing URL Detection Using Machine Learning

This project is a simple machine learning model to detect phishing websites based on URL features.

## 🚀 Features

- Uses Random Forest Classifier
- Trained on a dataset of phishing & legitimate URLs
- Accuracy and performance metrics shown
- Includes visualization with Confusion Matrix

## 📁 Project Structure

- `phishing_detector.py`: Main script with training and evaluation
- `notebooks/Phishing_Detector.ipynb`: Jupyter notebook version
- `data/phishing.csv`: Dataset
- `requirements.txt`: All dependencies

## 📊 Dataset

You can download the dataset from:
[Phishing Dataset CSV](https://www.kaggle.com/datasets/eswarchandt/phishing-website-detector)

Place the `phishing.csv` file in the `data/` folder.

## 🧠 Model

- Algorithm: Random Forest
- Metrics: Accuracy, Precision, Recall, F1-score
